Chọn file Excel dữ liệu, sau đó bấm chọn nút tính năng tương ứng ở bên dưới để hệ thống phân loại xử lý.

Chưa có file nào được chọn

⚠️ YÊU CẦU VỀ CẤU TRÚC FILE EXCEL MẪU:

  • Cột A: Mã Số Tài Khoản (Ví dụ Sinh viên: HE180000, Giảng viên: vinhnq)
  • Cột B: Họ và Tên thành viên
  • Cột C: Địa chỉ Email FPT (Ví dụ: tênsvhe180000@fpt.edu.vn hoặc cánbộ@fe.edu.vn)
  • Cột D: Mã Cơ Sở Học Tập/Làm Việc (Số từ 1 -> 5 tương ứng: Hà Nội, HCM, Đà Nẵng, Cần Thơ, Quy Nhơn)
